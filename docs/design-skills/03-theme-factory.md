# Theme Factory — Themes als geschlossene Token-Sets

Ein Theme ist ein vollstaendiges, benanntes Set aus Palette + Schriftpaar +
Charakterbeschreibung — nie eine lose Farbsammlung.

## Aufbau eines Themes

- **Name**, der den Charakter traegt (im Repo: das Marken-Theme aus DESIGN.md)
- **Palette**: 4–6 benannte Hexwerte mit Rolle (Basis, Flaeche, Akzent, Text)
- **Typo**: Display- und Body-Schrift als festes Paar
- **Einsatzbeschreibung**: wofuer das Theme gedacht ist

## Anwendung

1. Theme-Definition lesen (hier: DESIGN.md Abschnitte 2–4 und 9)
2. Farben und Schriften konsequent ueberall anwenden — keine Insellosungen
3. Kontrast und Lesbarkeit pruefen, bevor es als fertig gilt
4. Die visuelle Identitaet ueber alle Seiten/Sektionen durchhalten

## Fuer dieses Repo

Das Repo hat genau EIN Theme (Schwarz/Gold + Pink/Cyan-Nebenakzente).
Neue Unterbereiche bekommen kein neues Theme, sondern eine Variante innerhalb
der bestehenden Tokens (wie die Bereichsakzente in /control). Wenn wirklich
ein neues Theme noetig wird (z. B. Sonderevent): erst als komplettes Set
definieren, zeigen, freigeben lassen — dann anwenden.
