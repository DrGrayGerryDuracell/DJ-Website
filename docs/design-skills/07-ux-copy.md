# UX Copy — Interface-Texte

Fuenf Prinzipien: klar, knapp, konsistent, nuetzlich, menschlich.
Sprache im Dashboard: Deutsch, aktiv, konkret.

## Muster

- **Buttons/CTAs**: mit Verb beginnen, konkret: "Scan starten",
  "Aenderungen speichern" — nie "Absenden"/"OK". Der Name bleibt durch den
  ganzen Flow gleich: "Veroeffentlichen" -> Toast "Veroeffentlicht".
- **Fehler**: Was passiert ist + warum + wie beheben.
  "Upload fehlgeschlagen. Datei groesser als 50 MB. Komprimiere sie oder
  lade sie in Teilen hoch." Fehler entschuldigen sich nicht und sind nie vage.
- **Leere Zustaende**: Was das ist + warum leer + wie starten.
  "Noch keine Releases. Lege den ersten Katalog-Eintrag an." — nie nur
  "Keine Daten".
- **Bestaetigungsdialoge**: Aktion benennen ("3 Tracks loeschen?"),
  Konsequenz nennen ("Kann nicht rueckgaengig gemacht werden"), Buttons
  tragen die Aktion ("Tracks loeschen" / "Behalten"), nicht OK/Abbrechen.
- **Tooltips**: kurz, hilfreich, nie das Offensichtliche.
- **Ladezustaende**: Erwartung setzen, Unruhe nehmen.

## Ton

Erfolg: freudig, nicht ueberdreht. Fehler: hilfsbereit. Warnung: klar und
handlungsorientiert. Neutral: informativ und knapp. Ein Begriff behaelt
ueberall dieselbe Bedeutung — Vokabular ist die Beschilderung des Interfaces.
