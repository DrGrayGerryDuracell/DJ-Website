# Canvas Design — statische Grafik (Poster, Cover, Social)

Fuer alles Statische rund um Dr. Gray / Mrs. Dr. Gray: Event-Poster,
Release-Cover, Story-Grafiken, Header.

## Zwei-Schritt-Methode

1. **Design-Philosophie schreiben** (kurzes Manifest, 4–6 Absaetze): ein
   benanntes aesthetisches Konzept (z. B. "Golden Signal" — Gold als
   Lichtsignal im Schwarz), formuliert ueber Raum, Form, Farbe, Rhythmus,
   Hierarchie. Erst wenn das Manifest steht, wird gestaltet.
2. **Visuell ausdruecken**: Das Ergebnis ist zu ~90 % Bild und ~10 % Text.
   Information lebt im Design, nicht in Absaetzen.

## Prinzipien

- Text ist visuelles Element: wenige, wesentliche Worte, praezise gesetzt —
  grosse Einzelworte oder fluesterleise Labels, nie Textbloecke.
- Eine begrenzte, absichtsvolle Palette (hier: Schwarz, Gold, punktuell
  Pink/Cyan) statt vieler Farben.
- Wiederholung und Muster erzeugen Tiefe: akkumulierte Marken, Raster,
  geschichtete Pattern, die bei laengerem Hinsehen belohnen.
- Die Referenz zum Anlass (Track, Event, Ort) subtil einweben — wie ein
  Jazz-Zitat: Kenner spueren es, alle anderen sehen einfach ein starkes Bild.
- Nichts ragt aus dem Format, nichts ueberlappt unbeabsichtigt, ueberall
  Atemraum. Das Ergebnis muss aussehen, als haette ein Profi lange daran
  gearbeitet.
- Beim Verfeinern nichts hinzufuegen — vorhandenes schaerfen. Die Frage ist
  nie "was fehlt noch?", sondern "wie wird das Vorhandene mehr aus einem Guss?"
